adsbox.biz API

Paste the API address and key from adsbox.biz. The key is saved encrypted and is never shown again.
Every 30 minutes Boost Desk sends the boost spend of each Page per day (date, Page ID, spend) for the last 7 days, so adsbox.biz can show cost per order too. Re-sending a day corrects it — nothing is doubled. The key needs the adspend.write permission (Two-way) in adsbox.biz → Admin → API Connecting.

Check orders against adsbox.biz

Pick a day and compare Boost Desk's numbers with what adsbox.biz says right now. If adsbox's numbers match its Sales Overview, tap Use adsbox numbers.
